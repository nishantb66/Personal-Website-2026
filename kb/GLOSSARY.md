# Glossary

- App Router: Next.js file-based routing model under `src/app`.
- Client Component: React component marked with `"use client"` for browser-side interactivity.
- Constants Model: Static content object exports in `src/lib/constants.ts`.
- Design Tokens: CSS custom properties (`--background`, `--primary`, etc.) used by visual system classes.
- Panel: Reusable glass-like surface style defined in `globals.css`.
- Chip: Pill-shaped metadata tag style used for skills and technologies.
- CTA: Call-to-action button variants (`cta-primary`, `cta-ghost`).
- Kicker: Small uppercase section label with decorative lead line.
- Scroll Progress Bar: Top fixed animated bar driven by Framer Motion `useScroll`.
- Forced Theme: `next-themes` mode where a specific theme is always applied (`dark` in current layout).
- Static Asset: File under `public/` served directly at root URL path.
- Metadata: Page/site SEO metadata exported from `src/app/layout.tsx`.
