# Domain: Deployment & Operations - System Context

## Responsibility

Defines how the site is built, validated, and deployed.

## Primary Files

- `package.json` scripts
- `DEPLOYMENT.md`
- `next.config.ts`

## Commands

- `npm run dev`
- `npm run build`
- `npm run start`
- `npm run lint`

## Deployment Target

- Vercel-first deployment model.

## Constraints

- No environment variables are required for current feature set.
- Deployment quality depends on static asset presence and link correctness.
